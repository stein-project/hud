# HUD 0.1.10: Target element and a real ping

Requires Stein Loader 0.1.28.

- **Target** (new): who you are fighting — the last player you hit or, with no recent hit, the one under your crosshair. Shows the head, name, distance, health (the bar drops with the lost part fading slowly), armor and held item with each piece's durability. Range, time on screen, time to switch and each part are set in the Panel.
- **New defaults**: a fresh install starts with the elements already tuned.
- **Ping**: measured by the client itself, like the server list; it used to come from the Tab, which many servers leave at 0.
- **RAM**: shows the computer's (the one in Task Manager), in GB. The game's is gone: it rises and falls with Java's garbage collection and says nothing. If you had RAM on, the line stays.
- **Lighter minimap at high FPS**: chunks are read by time, not per frame; above 60 FPS it costs no more than it would at 60.
