# HUD 0.1.14: server rules

Some servers do not allow a minimap or information about other players. The HUD now respects that on those servers, and only there.

- **Off where a server forbids them**: on a server that does not allow them, the minimap (radar included), the target element and the distance in the Tab list stay off while you play there. They come back as soon as you leave.
- **You know why**: the HUD panel says which server keeps each one off.
- **Needs Stein Loader 0.1.28**, which comes with the pack 0.1.36.
